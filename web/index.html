BLONDA BRIS

TRUMMASKINEN

  • PLAY eller mellanslag startar och stoppar. Mönster 1 har en takt från början.
  • De 16 vita tangenterna är stegen för trumljudet som är valt: tryck för att sätta eller ta bort ett slag. De lyser där det slår.
  • De åtta första svarta väljer och spelar trumljud: BD SD RS CP CH OH TOM CB.
  • FX · SEL · ENV · LFO · EDIT · GLO är mönster 1–6. Håll ett och tryck ett annat för att kopiera.

RATTAR OCH KNAPPAR

  • KNOB1–4: trumljudets nivå, stämning, längd och karaktär. SELECT bläddrar till GLOBAL: tempo, swing, drivning, volym.
  • PRESETS byter trumset. ALGORITHM är ERA, som i BRIS.
  • OCT− / OCT+ (eller Z X): tempo −1 / +1.
  • REC spelar in det du spelar på närmaste steg. ARP sätter accenter. SEQ växlar till LIVE: alla tangenter spelar trumljud.
  • SAVE sparar trumset, mönster och tempo i den här webbläsaren.

SAMMA KOD SOM PÅ FM-1

Trummaskinen är exakt den modul som installeras på synthen, kompilerad till WebAssembly. Sekvensern går i ljudtråden och slagen hamnar på rätt sampel, som på FM-1. Ljudet är testat mot PULS i blonda-motor sampel för sampel.

Källkod och modulen för FM-1: github.com/victorysvensson-dev/blonda-fm1

SPELA

  • Klicka eller tryck på tangenterna, dra över dem för glissando.
  • Datorns tangentbord: A–Ä och raden ovanför. Z X byter oktav.
  • MIDI-keyboard i Chrome eller Edge: toner, böj, modhjul, tryck, sustain.

RATTAR OCH KNAPPAR

  • Dra rattarna upp och ner, eller rulla. PRESETS byter ljud.
  • ALGORITHM är ERA: från MODERN (rent) via TAPE (kassett som slits) till LOFI (färre bitar). Står uppe till höger på skärmen.
  • KNOB1–4 ändrar de fyra värdena på skärmen, SELECT bläddrar sidor.
  • SEL filter · EDIT osc · ENV höljen · LFO · FX · GLO röst. Tryck igen för andra halvan.
  • SAVE sparar ljudet i den här webbläsaren.

SAMMA KOD SOM PÅ FM-1

Skärmen, rattarna och ljudet kommer från exakt den modul som installeras på synthen, kompilerad till WebAssembly. Ljudet går i 44,1 kHz som på FM-1. Det som skiljer är själva panelen, och att styrkan här kommer från var du trycker: längre ner på tangenten spelar hårdare.
