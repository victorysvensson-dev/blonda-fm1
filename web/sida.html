BLONDA BRIS

SPELA

  • Klicka eller tryck på tangenterna, dra över dem för glissando.
  • Datorns tangentbord: A–Ä och raden ovanför. Z X byter oktav.
  • MIDI-keyboard i Chrome eller Edge: toner, böj, modhjul, tryck, sustain.

RATTAR OCH KNAPPAR

  • Dra rattarna upp och ner, eller rulla. PRESETS byter ljud.
  • KNOB1–4 ändrar de fyra värdena på skärmen, SELECT bläddrar sidor.
  • SEL filter · EDIT osc · ENV höljen · LFO · FX · GLO röst. Tryck igen för andra halvan.
  • SAVE sparar ljudet i den här webbläsaren.

SAMMA KOD SOM PÅ FM-1

Skärmen, rattarna och ljudet kommer från exakt den modul som installeras på synthen, kompilerad till WebAssembly. Ljudet går i 44,1 kHz som på FM-1. Det som skiljer är själva panelen, och att styrkan här kommer från var du trycker: längre ner på tangenten spelar hårdare.

Källkod och modulen för FM-1: github.com/victorysvensson-dev/blonda-fm1
